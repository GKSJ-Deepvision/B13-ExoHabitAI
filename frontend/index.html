How ExoHabitAI works

01
Data Collection

Sourced from NASA Exoplanet Archive. 39,386 raw observations filtered to 6,107 unique confirmed planets using validated default parameter sets.

02
Feature Engineering

Habitability Score Index (HSI), Stellar Compatibility Index, Orbital Stability Factor, and Stellar Flux computed from raw planetary/stellar parameters.

The Science

AI-driven exoplanet
habitability
research

ExoHabitAI transforms the NASA Exoplanet Archive into an intelligent habitability classifier. By training a Random Forest model on 991 confirmed exoplanets — filtered from 39,386 observations — we can predict whether a new planet could support life from 14 key parameters.

The Habitability Score Index (HSI) is our custom metric: a geometric mean of radius, temperature, and flux similarity to Earth. Planets above the HSI median are classified as potentially habitable.

Data Pipeline

01
Data collection

NASA Exoplanet Archive (Planetary Systems Composite). 39,386 rows × 289 features. Filtered to unique confirmed exoplanets using default_flag = 1.

NASA Archive6,107 planets
02
Preprocessing

Median imputation for missing values (~85% insolation flux, ~81% density, ~50% mass). Z-score filtering (|z|<3) then IQR capping. Log→linear luminosity conversion before imputation.

Python / Pandas
03
Feature engineering

Stellar Flux (inverse square law), Habitability Score Index (geometric mean of radius/temperature/flux similarity), Stellar Compatibility Index (Gaussian centered at 5778 K), Orbital Stability Factor (Kepler's Third Law).

Physics-based
04
Model training

4 models compared: Logistic Regression, Decision Tree (depth 5), Random Forest (n=100), XGBoost. Best selected by F1-score. GridSearchCV tuning: n_estimators=[100,200], max_depth=[5,10,None], min_samples_split=[2,5].

scikit-learn
05
API deployment

Flask REST API with 4 endpoints: /health, /model-info, /predict (POST), /rank (GET). Stellar Flux derived server-side. CORS-enabled. Logging via Python logging module.

FlaskProduction-ready
