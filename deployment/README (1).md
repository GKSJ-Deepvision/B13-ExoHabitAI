# 🚀 ExoHabitAI Deployment

ExoHabitAI is a machine learning web app that predicts whether an exoplanet could support life, built using NASA TESS data and a hybrid stacking ensemble model.

## 🌐 Live Website
**https://aman7297.github.io/exoHabitAiDetection/**

## 🏗️ Tech Stack
* **Frontend:** HTML, CSS, JavaScript — Deployed on GitHub Pages
* **Backend API:** Flask REST API — Deployed on Render
* **ML Model:** scikit-learn Pipeline (best_model.pkl) — Hosted on GitHub
* **Data:** NASA TESS Exoplanet Archive

## 📌 Note
The backend runs on Render's free tier, so the first request after inactivity may take around 30 seconds to respond. This is expected behavior.
